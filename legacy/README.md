# Legacy: the 1.x open core (Apache-2.0)

These are the packages (`legacy/protect` is the 1.9.0 CLI) this repository held up to June 2026 (`@nodatachat/protect` 1.9.0:
`init`, `encrypt`, `run`, `status`). They stay here, under Apache-2.0, as published.
They are not maintained.

The `protect` CLI moved to `@nodatachat/nodata`:

```bash
npm i -g @nodatachat/nodata
```

The current `@nodatachat/protect` (3.x) is NoData's verification layer, in
[`packages/protect`](../packages/protect).
